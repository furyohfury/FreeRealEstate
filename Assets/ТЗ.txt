ТЗ
Игра в 3D. Есть от 3 до 5 конвейерных дорожек расположенных вертикально. У каждой дорожки свой цвет. По ним сверху вниз идут предметы, также этих цветов. Есть хп игрока.
Нужно чтобы до низа на каждом конвейере дошли предметы цвета конвейера. Для этого предметы можно передвигать между конвейерами либо свайпом просто по горизонтали, либо зажав курсор/палец на предмете и двигая его. При столкновении с другими предметами, они сбивают их с конвейеров и уничтожают. За успешное достижение предметом низа конвейера своего цвета, хп игрока немного восстанавливается, за сбитие с конвейера немного вычитается, за достижение низа предмета не того цвета, вычитается много хп.
Есть 3 уровня сложности с 3, 4 и 5 конвейерами. Скорость конвейеров увеличивается со временем
Цель продержаться как можно больше времени
При смерти игрока, можно посмотреть видео, после чего восстановится половина хп, очистится экран от предметов и немного сбросится скорость конвейеров

SDK:
Реклама гугла/яндекса в зависимости от платформы. На пк можно убрать
Аналитика посмотреть самую юзаемую и отправлять например результаты игроков, сколько сессий было. Можно сделать небольшое текстовое поле в игре типа «Сегодня n игроков» или попап со статой хз.

VFX:
При попадании — минифанфары с эффектом
При сбитии — постепенное как бы падение в пропасть через уменьшение скейла и эффект маленького взрыва
При засчете неверного предмета — тряска экрана и звук и подсвечивание красным низа конвейера

Опционально:
Ввести бонусные предметы за либо временные границы (продержался n секунд), либо за идеальную игру в течение m секунд. Например предмет очищающий полностью экран.
Также предмет можно получить раз в день или перед забегом посмотрев рекламу.
Шкала паверапа заполняющаяся при идеальной игре.
Радужные предметы любого цвета. Можно сделать к ним шейдеры

Фишки
Иконка в виде орущего на конвейер мужика



План работ (порядок: кор геймплей → интеграция SDK → VFX & SFX → опциональные фичи)
1. Кор игровой механизм (ядро)
Структура сцены и основные префабы
Создать сцену GameScene с ортографической или перспективной камерой (по стилю).
Префабы:
•		
 	Lane 	(конвейер) — X позиция, цвет, нижняя зона 	(target zone).
•		
 	Item 	(предмет) — mesh/quad + material + script (ConveyorItem).
•		
 	PlayerHUD 	(HP, score, timer, powerbar).
Архитектура и основные менеджеры (скелет)
GameManager — состояние игры (Running, Paused, Dead, Revived), общие параметры (maxHP).
SpawnManager — логика спавна предметов в lanes.
LaneManager — хранит массив lanes, управление скоростью по laneCount/difficulty.
ItemController / ConveyorItem — поведение отдельного предмета (позиционирование в lane, переход между lanes, падение/уничтожение).
InputManager — обработка свайпов и drag & drop.
PoolManager — object pooling для предметов и VFX.
UIManager — экраны, кнопки, popup для рекламы, отображение HP.
AudioManager — проигрывание SFX / музыка.
AdsManager & AnalyticsManager (интерфейсы, имплементацию делать позже на стадии SDK).
Представление конвейеров и движение предметов
Представь каждую дорожку как «колонку» с Y координатой движения вниз.
Реализовать движение предмета: item.Y -= speed * deltaTime.
Поддерживать порядок предметов в lane (список/очередь) — это упрощает проверку столкновений и попадания в низ.
Логика смены дорожки и столкновений
Варианты ввода:
•		
 	Swipe 	horizontal: свайп влево/вправо по экрану — 	переключает выбранный/активный предмет 	(или ближайший сверху). Можно сделать 	дотвином rb.movetoposition с 	easing замедлением 	в конце
•		
 	Drag: 	удержать предмет и вести курсором.
1.		
 	Попадание 	в низ и изменение HP/очки
Если item.Y <= targetY:
•		
 	Если 	item.color == lane.color → восстановление HP (cap на 	maxHP) + начисление очков/монет.
•		
 	Если 	item.color != lane.color → сильная потеря HP + 	визуальная индикация (shake + подсветка).
При уничтожении в столкновении → небольшая потеря HP.
При достижении HP <= 0 → состояние Dead (вызывать Game Over flow).
Скорость и сложность
GameplayStarter, в нем ConveyorFactory, столько сколько в текущем выбранном режиме
Три сложности: laneCount = 3 / 4 / 5. При смене сложности пересоздать lanes и параметры spawn.
Скорость конвейеров = baseSpeed + speedRamp * timeSurvived. Можно управлять через кривую (AnimationCurve) для тонкой настройки.
Spawn rates: baseSpawnInterval * random(0.8–1.2). Шанс спавна «неправильного» цвета растёт с временем.

 ▎3. VFX и SFX (порядок работ и необходимые эффекты)

 1. Базовый VFX список (реализация через Unity Particle System / VFX Graph минимально)

 – Hit (успешное попадание в низ своего цвета): маленькая фанафара + burst частиц (цвет lane).

 – Collision destruction: постепенное «падение в пропасть» — анимация scale → 0 + небольшой explosion particle + fadeout.

 – Wrong color scored: камера shake + highlight нижней зоны красным (UI overlay flash) + heavy sound.

 – Item move between lanes: небольшая trail/afterimage или motion blur для более приятной анимации.

 – Revive / Ad reward: крупный clear screen VFX (wave + particles) при очистке.

 – Rainbow item shader: простой shader (Unlit) с HSV shift или scrolling gradient для «радужного» эффекта.

 2. Техническая реализация VFX

 – Все VFX через PoolManager (чтобы не создавать/уничтожать объекты часто).

 – Параметризованные префабы VFX (цвет соответствует lane.color).

 – CameraShake компонент для screen shake (короткая кривая интенсивности).

 – Использовать URP простые bloom/post processing по вкусу, но минимизируй для мобилок.

 3. SFX и музыка

 – Набор звуков:

 – success_hit.wav (попадание)

 – collision_destroy.wav (столкновение)

 – wrong_score.wav (неверный)

 – uiconfirm.wav, uicancel.wav

 – adrewardedstart/complete

 – background_loop.wav (лёгкая музыка)

 – Реализация:

 – AudioManager с AudioMixer (группы: SFX, Music).

 – Пул звуков не обязателен, но кэшировать AudioClips и использовать PlayOneShot.

 – Регулировка громкости в настройках.

 4. Интеграция VFX/SFX в игровые события

 – При попадании/столкновении/неверном счёте — вызывать соответствующие VFX и SFX через VFXManager/AudioManager.

 – Добавить визуальные фидбэки на кнопки/интерактивные действия (scale button, brief highlight).

 ▎4. Опциональные фичи и расширения (после MVP)

 1. Бонусные предметы и powerbar

 – Бонусные предметы: ClearScreen, SlowDown, Shield — могут попадаться рандомно или как награда за «идеальную игру m секунд».

 – Powerbar:

 – Заполняется при «идеальной игре» (например, n секунд без ошибок).

 – При заполнении даёт выпадение бонусного предмета или активирует ульту (очистка экрана).

 – Реализация: добавить item.type enum { Normal, BonusClear, BonusSlow, Rainbow }.

 2. Дневной rewarded / pre run reward

 – Реализовать daily spinner или просто daily claim, который даёт один бонусный предмет при просмотре рекламы.

 – Хранить дату последнего клика (PlayerPrefs).

 3. Rainbow items

 – Радужный предмет любого цвета: при достижении низа счёт считается как правильный для всех lanes или даёт особый эффект.

 – Shader: Unlit с scrolling gradient / HSV shift. Можно сделать простую анимацию цветовой маски.

 4. Магазин / косметика

 – Скины для предметов/фон/конвейерных полос за монеты.

 – IAP: отключение рекламы или покупка стартового набора бонусов.

 5. Лидерборды и достижения

 – Отображение лучших результатов.
